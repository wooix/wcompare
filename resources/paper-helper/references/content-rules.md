# 번역과 읽기 흐름

원문의 전체 구조를 읽고 sourceInventory를 먼저 작성한다. 원문 단위마다 원문 위치와 영어 문장 또는 정리된 HTML을 보존한다. 번역 단위의 sourceId로 그 원문과 연결한다. 중요한 주장, 조건, 예외, 불확실성, 수식, 실험 조건과 인용을 대조한다.

전문 용어는 모든 등장 위치에서 English (한국어)로 병기한다. 용어집에서 사용자가 제거한 항목은 영어만 표시한다. 최초 등장 이후에도 기본 병기를 유지한다. 약어, 단수·복수 등을 함께 적용할 때에는 실제로 같은 개념인지 확인한다.

본문에는 원문의 주장과 근거를 유지한다. 읽기 전 안내, 비유, 직관, 주제별 정리와 연결 설명에는 AI 보조 설명 표시를 사용한다. 원문의 부연 설명 상자는 원문 보충 설명으로 표시한다.

각 장에는 읽기 전 안내와 마무리 요점을 작성한다. 주제가 끝나는 곳에는 필요한 짧은 정리를 배치한다. 이해에 필요한 배경과 부록은 해당 위치의 companions에 연결한다. 각 부록의 제목과 순서는 원문에서 가져온다.

그림과 표의 위치, 설명, 수식과 기호를 보존한다. 수식은 원문의 MathML을 복사해 재사용한다. 그림 내부의 원문 표기를 보존할 때에는 필요한 한국어 풀이를 그림 설명에 함께 둔다. 그림 파일은 입력 JSON 곁에 두고 상대 경로로 참조한다.

코드, 실험용 문장과 고유명사는 원문 표기가 필요한 범위를 유지한다. 참고문헌의 이름과 서명은 원문과 대조할 수 있는 표기로 제공한다.

입력 데이터의 sourceInventory는 번역 전에 원문에서 수집한 목록이다. 빌더의 누락 검사는 이 목록을 기준으로 한다. 원문 전체와 목록의 대응 여부 및 번역의 의미 정확성은 별도로 검토한다.
