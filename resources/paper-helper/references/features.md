# 고정 화면과 기능

이 명세는 현재 읽기 사이트의 공통 화면을 코드로 보존한 버전 1.0.0에 해당한다. 실제 출력에는 assets/site의 파일을 그대로 복사한다. template-lock.json의 파일 목록과 SHA-256이 빌드에 사용한 버전을 확인한다.

## 화면 배치

| 화면 | 배치 |
|---|---|
| 1220px 초과 | 왼쪽 목차 300px, 가운데 본문, 오른쪽 보충 자료 215px. 본문 영역의 좌우 여백과 열 간격은 35px |
| 761–1220px | 왼쪽 목차 235px, 가운데 본문. 보충 자료는 상단 자료 메뉴에서 열기 |

| 상단 도구 | 데스크톱 높이 69px, 모바일 58px. 스크롤 중 상단에 유지 |
| 보충 자료 패널 | 오른쪽에서 열리는 전체 높이 패널. 최대 660px 또는 화면의 96% |

## 메뉴와 상태

상단은 현재 장, 모바일 자료 버튼, 원문 함께, 글자 작게·크게, 밝기 버튼 순서다. 목차 상단에는 검색, 전체 펼치기·접기, 현재 위치가 있다. 목차 하단에는 읽은 장과 이어서 읽기가 있다.

본문의 원문 번역, 원문 보충 설명, AI 보조 설명은 기존 클래스와 표시를 사용한다. 하이라이트는 수식과 용어 설정을 보존한다. 현재 목차의 선택 상태는 읽는 위치에 따라 갱신한다.

자료 상태는 브라우저에 저장한다. 용어 표시 설정은 같은 사이트에서 공통으로 적용한다. 하이라이트는 논문 ID와 버전에 연결하고, 읽기 위치와 읽은 장은 논문 ID별로 저장한다.

## 확인 방법

서로 다른 장 수의 입력을 빌드하여 UI 파일의 해시가 같은지 확인한다. 같은 화면 폭에서 글꼴·색상·목차 폭·상단 높이·열 간격을 비교한다. 메뉴 동작, 용어 제거·복원, 하이라이트, 원문 대조, 검색, 자동 이어 읽기, 모바일과 오프라인을 검사한다.

최종 생성물은 verify_output.py로 다시 검사한다. 이 검사는 생성 뒤에 변경된 HTML·CSS·글꼴·공통 기능 파일을 찾는다.

동일한 템플릿 버전은 동일한 UI 파일을 사용한다. 글줄의 길이와 전체 페이지 높이는 논문 내용에 따라 달라진다. 글자의 픽셀 표현은 브라우저와 운영체제의 렌더링에도 영향을 받는다.
